コードを分析して、回転が動作しない原因を特定します。

## 原因報告

主な問題は **`setClawOpen01` 関数が `CLAW_AXIS` / `CLAW_SIGN` の設定値を完全に無視している**ことです。

ファイル冒頭でこう定義されています：

```js
let CLAW_AXIS = "x";   // "x" | "y" | "z" を試す
let CLAW_SIGN = 1;      // 1 か -1 を試す
```

しかし `setClawOpen01` は常に `.rotation.x` をハードコードしており、`CLAW_AXIS` を `"y"` や `"z"` に変えても反映されません：

```js
function setClawOpen01(open01) {
  // ...
  clawLPivot.rotation.x = l;  // ← 常にx軸固定
  clawRPivot.rotation.x = r;  // ← 同上
}
```

加えて `CLAW_SIGN` も未使用なので、回転方向の反転も効きません。さらに、`clawLPivot` / `clawRPivot` が初期化前に呼ばれた場合のnullガードもありません。

## 修正

`setClawOpen01` を以下のように書き換えてください：

```js
function setClawOpen01(open01) {
  if (!clawLPivot || !clawRPivot) return;           // null ガード

  const l = THREE.MathUtils.lerp(CLAW_L_CLOSED, CLAW_L_OPEN, open01) * CLAW_SIGN;
  const r = THREE.MathUtils.lerp(CLAW_R_CLOSED, CLAW_R_OPEN, open01) * CLAW_SIGN;

  // CLAW_AXIS に従って正しい軸に回転を適用
  clawLPivot.rotation.set(0, 0, 0);
  clawRPivot.rotation.set(0, 0, 0);
  clawLPivot.rotation[CLAW_AXIS] = l;
  clawRPivot.rotation[CLAW_AXIS] = r;
}
```

これにより、冒頭の `CLAW_AXIS` を `"x"` / `"y"` / `"z"` に、`CLAW_SIGN` を `1` / `-1` に変えるだけで、回転軸と方向を正しく切り替えられるようになります。モデルに合う軸と符号の組み合わせを試してみてください。
