# Step4 修正: 持ち上げ時に爪を閉じ直さない

## 変更箇所: `autoStep === 4` 内の `else` ブロック（1箇所のみ）

### 変更前

```javascript
    } else {
      if (step4PressureLatched) {
        // 圧迫が解消された → 一定時間待ってからラッチ解除
        step4PressureReleasedT += dt;
        if (step4PressureReleasedT >= STEP4_PRESSURE_RECLOSE_DELAY) {
          step4PressureLatched = false;
          step4PressureReleasedT = 0;
        }
        // 待機中は現在角度を維持（閉じも開きもしない）
      } else {
        // ラッチ解除済み → 通常の閉じ駆動
        if (clawOpen01 > 0) {
          setClawOpen01(clawOpen01 - (dt / CLAW_CLOSE_TIME), dt);
        }
      }
    }
```

### 変更後

```javascript
    } else {
      if (step4PressureLatched) {
        // 圧迫が解消された → 一定時間待ってからラッチ解除
        step4PressureReleasedT += dt;
        if (step4PressureReleasedT >= STEP4_PRESSURE_RECLOSE_DELAY) {
          step4PressureLatched = false;
          step4PressureReleasedT = 0;
        }
      }
      // ラッチ解除後も閉じ駆動はしない。Step3終了時の角度をそのまま維持して持ち上げる。
    }
```

## 何が変わるか

- **削除**: `else { ... setClawOpen01(clawOpen01 - (dt / CLAW_CLOSE_TIME), dt); }` — ラッチ解除後に爪を閉じ直す処理
- **効果**: Step3（閉じ工程）で圧迫停止した角度をそのまま保持したまま持ち上げる。無理な圧力をかけなくなる。
